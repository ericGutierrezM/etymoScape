# UI ideas

## Must-have for MVP

- Big word title and language
- Short readable explanation at the top
- Etymology chain visible immediately
- Map route
- Animation along map route
- Timeline
- Interactive graph
- Semantic notes
- Sources and confidence labels
- Raw data/debug tab for development

## Nice-to-have later

- Shareable image card
- “Explain like I’m 12” mode
- Show related words
- Language influence explorer
- False friend warning
- Filter graph by relation type

## Open questions

- Should map or graph appear first?
- Should semantic drift be a tab or a section?
- How much text should appear before visualizations?
- Should uncertainty be shown as colors, badges, or edge styles?
